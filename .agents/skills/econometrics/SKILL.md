# 계량경제학
연구 질문, 분석 단위, 변수, 기간, 식별 전략을 먼저 확인한다. OLS, 패널, 시계열, DiD, IV의 적합성을 비교하되 필요한 경우에만 사용한다. 강건/군집/HAC 표준오차의 선택 근거를 설명한다. 계수 단위, 신뢰구간, 표본수, 가정 및 한계를 기록한다. 인과효과를 무근거 단정하지 않는다. docs/analysis.md를 참고한다.
