# 계량경제학 분석 절차
1. 연구 질문, 관측 단위(거래/가맹점/지역/월), 모집단, 표본 기간을 정의한다.
2. 데이터 사전 및 단위, 환불/취소, 중복, 결측, 표본 선정 규칙을 확인한다. 원본 변경 금지.
3. 필요한 열을 DuckDB로 집계한 후 작은 결과만 Python으로 가져온다. 시간/지역별 집계 시 개인정보 반출 기준을 준수한다.
4. 탐색적 분석 후 OLS/패널/시계열/DiD/IV 등을 연구 설계에 맞게 선택. 모형 선택은 p-value만으로 하지 않는다.
5. 표준오차는 데이터 구조에 맞게 선택(HC, 군집, HAC 등). 패널의 단위 및 시간 효과, 시계열의 추세/계절성/자기상관, DiD의 평행추세 및 처치 시점, IV의 관련성 및 배제 제한 등을 검토한다. 가정은 검정 하나로 확정되지 않는다.
6. 계수 단위, 효과크기, 신뢰구간, 표본수, 분석 제외 기준, 모형 가정과 한계 기록. 인과 식별이 부족하면 연관성으로 표현.
7. 가상 데이터 테스트, 대안 사양 및 민감도 분석. 데이터 버전, 코드 커밋, 패키지 버전, 실행 날짜 및 난수 시드 기록(민감 메타데이터는 로컬 전용).
