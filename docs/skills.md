# Skills 사용과 외부 도구
기본 제공 Skills는 이 저장소에서 직접 작성한 경량 업무 지침입니다. Codex와 Claude용 사본을 제공합니다.
Superpowers, Grill Me, Ponytail 등 외부 Skills는 필수가 아닙니다. 각각의 공식 저장소, 라이선스, 버전, 설치 방식, 실행 스크립트와 네트워크/파일 접근을 검토한 후 별도로 적용하세요. 이름만으로 출처를 특정하지 않으며 여기에는 외부 코드를 복제하거나 설치하지 않았습니다.
초보자에게 필요한 핵심(요구사항 질문, 단순한 해결책, 실행 검증)은 기본 제공 지침에 반영했습니다. 도구마다 Skills 탐색 위치 및 지원이 다를 수 있으므로 자동 인식이 되지 않으면 AI에게 SKILL.md를 직접 읽으라고 요청하세요.
