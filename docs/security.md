# 데이터 보안 (필수)
카드 결제 데이터가 마스킹되어 있어도 날짜·금액·가맹점·지역 조합으로 개인 식별 위험이 남을 수 있습니다. 제공기관, 회사, 연구실의 데이터 이용 계약과 외부 AI 사용 승인 여부를 확인하세요.
- 승인 전 실제 데이터가 있는 폴더를 AI 앱/IDE 에이전트에 열지 않습니다. AI 도구가 실행한 명령 결과도 원격 모델로 전달될 수 있습니다.
- AI는 가상 데이터로 코드 작성 및 검증. 실제 실행은 AI가 연결되지 않은 별도 허용 환경에서 사람이 직접 수행. 코드 자체에 네트워크 전송 기능이 없는지도 검토.
- 실제 경로, 열 이름, 개별 행, 소수 집계, 에러 로그, 노트북 출력 등도 공유 전 검토. 승인된 최소 범위만 사용. 데이터 제공자의 반출 기준이 우선.
- 실제 데이터 및 파생물은 저장소 외부 접근 제한 폴더에 저장. 원본 읽기 전용 권한 설정을 권장. 복사/백업도 기관 정책에 따름.
- GitHub Private도 외부 서비스. 원본/결과를 올리지 않음. .gitignore는 실수 완화일 뿐, 이미 추적한 파일·강제 추가·다른 경로·로그를 막지 못함.
- git status, git diff --cached를 실제 내용 노출 없이 사람이 직접 검토. 민감 데이터가 커밋되었다면 push 중단, 관리자에게 알리고 저장소 이력 및 캐시 처리 절차를 따름. 단순 삭제로 해결되지 않음.
- AGENTS.md/Skills는 보안 경계가 아님. 강제 통제는 OS 권한, 격리, 네트워크 정책 및 승인된 서비스로 구현.
